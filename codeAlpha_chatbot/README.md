# Basic Chatbot 🤖

## Project Overview

This project is a simple rule-based chatbot developed using Python. 
The chatbot interacts with the user through the command line and provides predefined responses based on the user's input.

## Features

- Greets the user when they type "hello"
- Responds to "how are you"
- Tells its name when asked
- Ends the conversation when the user types "bye"
- Handles unknown inputs with a default response

## Technologies Used

- Python
- if-elif-else statements
- while loop
- Functions
- User input and output
- String methods

## How to Run

1. Make sure Python is installed on your computer.
2. Open the project folder in CMD or VS Code.
3. Run the following command:

```bash
python chatbot.py
