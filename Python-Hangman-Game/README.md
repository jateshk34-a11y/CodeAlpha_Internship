# Hangman Game 🎯

A Python-based terminal game developed as part of my CodeAlpha Internship.

## About the Project

Hangman is a word-guessing game in which the player guesses letters to discover a hidden word. The game uses a word list and tracks the player's guesses.

## Features

- Random word selection
- Letter-by-letter guessing
- Tracks guessed letters
- Uses a text file containing words

## Technologies Used

- Python
- Random module
- File handling
- Lists and loops

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open a terminal inside the `codeAlpha_Hangman` folder.
4. Run:

```bash
python Hangman.py
```

Make sure `word.txt` is present in the same folder.

## Concepts Practiced

- Variables and data types
- Loops and conditional statements
- Functions
- Random selection
- Reading data from a text file
